# 🌿 Personal Communication Blog - Green Nature Theme

Welcome to your beautifully styled green-themed blog! This theme is designed specifically for your personal communication projects with a natural, calming aesthetic.

## Theme Features

The green nature theme includes:

- **Forest-inspired color palette** - Deep greens, earth tones, and natural accents
- **Modern card layouts** - Perfect for showcasing your UTS projects
- **Responsive design** - Looks great on all devices
- **Enhanced typography** - Readable and elegant text styling
- **Custom callouts** - Special styling for different content types

- **Light Green**: Sage green (#7bc899)

## Styling Files Created

The following SCSS files have been created/updated for your green theme:

1. **`green-nature.scss`** - Color palette and CSS custom properties
2. **`custom.scss`** - Main styling with green theme components
3. **`variables.scss`** - Enhanced layout variables and spacing
4. **`callouts.scss`** - Special callout styling for UTS content
5. **`syntax.scss`** - Code highlighting that matches the theme

## Usage Tips

- Use the special callout types for your UTS sections
- The theme automatically styles markdown content beautifully
- Card layouts work great for project showcases
- All colors maintain good accessibility contrast ratios
